## 2. Logic Chain

1. **HUD Data Propagation**:
   - `DrawSystem.Draw()` queries the player component `ecs.Player`.
   - By capturing `hasArmor = p.ArmorEquipped`, `armorDurability = p.ArmorDurability`, `armorMaxDurability = p.ArmorMaxDurability`, and `armorDefense = p.ArmorDefense`, the UI renderer has all state necessary to draw the durability bar and status text.

2. **HUD Coordinate Alignment & Formatting**:
   - Health Bar occupies `Y=10..30` (`H=20`).
   - Hunger Bar occupies `Y=35..50` (`H=15`).
   - Thirst Bar occupies `Y=55..70` (`H=15`).
   - Placing the Armor Durability Bar at `Y=75..90` (`H=15`, `W=200`) creates a uniform 5px vertical spacing between bars.
   - Background Color: Dark Slate Navy (`color.RGBA{30, 45, 60, 255}`).
   - Foreground Fill: Steel Blue (`color.RGBA{70, 130, 180, 255}`).
   - Width formula: `armorW = float32(float64(armorDurability) / float64(armorMaxDurability) * 200.0)`, clamped `[0, 200]`.
   - Status text: `fmt.Sprintf("Armor: %d/%d (Def: %d%%)", armorDurability, armorMaxDurability, int(armorDefense*100))` printed at `(15, 75)`. When unarmored: `"Armor: NONE"`.
   - Shifting subsequent elements down by 20px (`Weapon` at `Y=95`, `INFECTED!` at `Y=115`) prevents text overlap and maintains a clean vertical stack.

3. **Visual Feedback on Player Entity**:
   - When `hasArmor` is true (and player is alive and uninfected), applying a metallic steel-blue color scale `op.ColorScale.Scale(0.75, 0.85, 1.25, 1.0)` provides instant, unambiguous visual confirmation that tactical armor is equipped.
   - Preserves death tint (`0.3, 0.3, 0.3, 1`) and infection pulse priority if those states occur.

4. **Test Suite Design Strategy (`internal/game/armor_test.go`)**:
   - Tests run headlessly using `arkecs.World` and `UpdateSystem` without requiring GUI display or audio hardware.
   - Every requirement from Milestone 3 must be verified by deterministic unit tests:
     a. **Equipping**: Using `"armor"` slot populates all 6 armor fields and removes the item from inventory.
     b. **Damage Mitigation**: Infected health drain is reduced by `(1.0 - ArmorDefense)`.
     c. **Infection Deflection**: Contact with zombie checks `InfectionResist`. Testing with 1.0 (guaranteed deflection) and 0.0 (guaranteed penetration) verifies deflection logic.
     d. **Durability Decay**: Zombie contact decrements `ArmorDurability` by 1 per hit.
     e. **Breakage on 0 Durability**: When durability hits 0, `ArmorEquipped` flips to `false` and subsequent attacks penetrate freely.
     f. **HUD Calculations**: Verifies width calculation clamping and text string formatting.

---

## 3. Caveats

- **No GUI in CI/Headless**: `DrawSystem.Draw()` requires an `*ebiten.Image` target. In headless unit tests (`go test`), UI logic is tested via calculation helpers and component state assertions. Full rendering runs during `ebiten.RunGame()`.
- **Infection Penetration Randomness**: In real gameplay, `rand.Float64() < player.InfectionResist` is probabilistic (70% deflect). In unit tests, setting `InfectionResist` to `1.0` and `0.0` guarantees deterministic verification.

// 2. Test Damage Mitigation (Health Drain Reduction)
func TestArmor_DamageMitigation_HealthDrain(t *testing.T) {
	// Unarmored infected player
	w1, _, sys1, pEnt1 := setupTestGame()
	pMap1 := arkecs.NewMap1[ecs.Player](w1)
	unarmored := pMap1.Get(pEnt1)
	unarmored.Infected = true
	unarmored.ArmorEquipped = false
	unarmored.ArmorDefense = 0.0

	// Armored infected player (50% defense)
	w2, _, sys2, pEnt2 := setupTestGame()
	pMap2 := arkecs.NewMap1[ecs.Player](w2)
	armored := pMap2.Get(pEnt2)
	armored.Infected = true
	armored.ArmorEquipped = true
	armored.ArmorDefense = 0.50

	// Run 100 combat/input update frames
	for i := 0; i < 100; i++ {
		sys1.processInputAndCombat()
		sys2.processInputAndCombat()
	}

	lossUnarmored := 100.0 - unarmored.Health
	lossArmored := 100.0 - armored.Health

	t.Logf("Unarmored HP Loss: %f, Armored HP Loss: %f", lossUnarmored, lossArmored)

	// Armored player should lose less health than unarmored player
	if lossArmored >= lossUnarmored {
		t.Errorf("Expected armored damage (%f) to be strictly less than unarmored damage (%f)", lossArmored, lossUnarmored)
	}

	// Verify exact 50% damage reduction ratio
	expectedMitigationRatio := 0.50
	actualMitigationRatio := 1.0 - (lossArmored / lossUnarmored)
	if math.Abs(actualMitigationRatio-expectedMitigationRatio) > 0.05 {
		t.Errorf("Expected mitigation ratio ~0.50, got %f", actualMitigationRatio)
	}
}

// 6. Test Multi-Hit Degradation Loop
func TestArmor_MultiHitDegradation(t *testing.T) {
	w, _, updateSys, pEnt := setupTestGame()
	pMap := arkecs.NewMap1[ecs.Player](w)
	player := pMap.Get(pEnt)

	initialDurability := 5
	player.ArmorEquipped = true
	player.ArmorDurability = initialDurability
	player.ArmorMaxDurability = 5
	player.ArmorDefense = 0.50
	player.InfectionResist = 1.0

	zombieMap := arkecs.NewMap5[ecs.Zombie, ecs.Position, ecs.Velocity, ecs.Sprite, ecs.Collider](w)
	zombieMap.NewEntity(
		&ecs.Zombie{Speed: 1.0, Chasing: true},
		&ecs.Position{X: 105, Y: 100},
		&ecs.Velocity{X: 0, Y: 0},
		&ecs.Sprite{Color: color.RGBA{255, 0, 0, 255}, W: 16, H: 16},
		&ecs.Collider{Width: 16, Height: 16},
	)

	for hit := 1; hit <= initialDurability; hit++ {
		expectedRemaining := initialDurability - hit
		updateSys.processZombies()

		if player.ArmorDurability != expectedRemaining {
			t.Errorf("Hit %d: Expected durability %d, got %d", hit, expectedRemaining, player.ArmorDurability)
		}

		if hit < initialDurability {
			if !player.ArmorEquipped {
				t.Errorf("Hit %d: Armor unexpectedly unequipped early", hit)
			}
		} else {
			if player.ArmorEquipped {
				t.Errorf("Hit %d: Armor should be unequipped at 0 durability", hit)
			}
		}
	}
}

// 7. Test HUD Calculations (Width scaling & String formatting)
func TestArmor_HUDCalculations(t *testing.T) {
	calcWidth := func(durability, maxDurability int) float32 {
		if maxDurability <= 0 || durability <= 0 {
			return 0
		}
		w := float32(float64(durability) / float64(maxDurability) * 200.0)
		if w > 200 {
			w = 200
		}
		if w < 0 {
			w = 0
		}
		return w
	}

	tests := []struct {
		name      string
		dur, max  int
		wantWidth float32
	}{
		{"Full Durability", 10, 10, 200.0},
		{"Half Durability", 5, 10, 100.0},
		{"Quarter Durability", 25, 100, 50.0},
		{"Zero Durability", 0, 10, 0.0},
		{"Negative Durability Clamped", -3, 10, 0.0},
		{"Over-Capacity Clamped", 15, 10, 200.0},
	}

	for _, tt := range tests {
